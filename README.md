# Vivi 🎻

바이올린 연습 도우미: 포지션별 음 위치, 오선보 음 읽기와 운지 퀴즈, 튜너, 메트로놈, 음감 훈련, 롱톤(지속음) 판정 기능을 제공하는 Blazor WebAssembly PWA입니다.

## 실행

```bash
dotnet watch --project src/Vivi
```

## 배포

`main` 브랜치에 푸시하면 GitHub Actions가 테스트, 퍼블리시, GitHub Pages 배포를 수행합니다.
저장소 Settings → Pages → Source를 **GitHub Actions**로 설정해야 합니다.

모바일 브라우저로 접속한 뒤 **홈 화면에 추가**(또는 **앱 설치**)로 설치합니다.
